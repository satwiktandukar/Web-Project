# HTML Tech Portal

A multi-page technology-focused website built using HTML, CSS, and JavaScript.

This project was created to practice frontend web development fundamentals, responsive layouts, navigation systems, themed UI design, and multi-page website structure.

## Features

- Multi-page website architecture
- Responsive frontend layout
- Technology category navigation
- News/article-style sections
- Custom UI themes
- Interactive navigation components
